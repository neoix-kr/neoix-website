발송 대상 — 명

· 앱에 로그인한 사용자에게만 전달됩니다.
· iOS는 즉시, 안드로이드는 Firebase 연결 후 발송됩니다.

앱 원격설정

앱을 다시 배포하지 않고 강제 업데이트 · 점검 모드 · 공지 배너 · 기능 켜고 끄기를 바꿔요. 저장하면 앱을 다시 켜거나 백그라운드에서 돌아올 때 바로 반영돼요.

저장하지 않은 변경이 있어요.

🚧 점검 모드

켜면 전 사용자가 즉시 앱을 쓸 수 없어요. 로그인 화면도 안 뜨고 점검 안내만 보여요. 서버 작업이 끝나면 반드시 다시 꺼주세요.

비우면 "더 나은 서비스를 위해 잠시 점검 중이에요."가 보여요.

⬆️ 업데이트 게이트

버전은 x.y.z 형식만 인정해요. v1.2.0이나 1.2로 저장하면 앱이 버전을 못 읽어 강제 업데이트가 조용히 풀려요.

강제 — 이 버전 미만은 업데이트 전까지 앱 사용 불가(차단).
권장 — 이 버전 미만이면 배너로 안내, "나중에" 누르고 계속 사용 가능.

📢 공지 배너

공지 ID를 새로 바꿔야 "다시 보지 않기"를 누른 사용자에게도 공지가 다시 떠요. 내용만 고치고 ID를 그대로 두면 이미 닫은 사람에겐 안 보여요. 제목이 비어 있으면 배너 자체가 뜨지 않아요.

🔗 스토어 링크

차단 화면의 "업데이트하러 가기" 버튼이 여는 주소예요. 비어 있으면 스토어 검색 화면으로만 보내서 사용자가 헤맬 수 있어요.

🎛️ 기능 켜고 끄기

문제가 생긴 기능만 골라서 끌 수 있어요. 앱은 꺼짐(false)일 때만 기능을 숨기고, 목록에 없는 기능은 켜진 것으로 봐요 — 그래서 켜짐은 기본값과 같아요.
