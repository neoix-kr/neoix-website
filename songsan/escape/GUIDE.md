## 1. 이 게임이 무엇인가

학생 **네 명이 한 팀**이 되어, **태블릿 한 대**를 들고 **배 안을 돌아다니며** 문제를 풀어 나갑니다.
이야기는 이렇습니다.

> 저 바다 끝에 **등대가 꺼져 있다.**
> 배를 띄워 폭풍을 넘고, 무덤 섬에 내렸다가, 항구로 돌아와,
> 항해하며 모은 물건으로 **등대에 다시 불을 켠다.**

**전부 여섯 단계(막)** 이고, 각 단계는 여름성경학교 설교 한 편과 짝을 이룹니다.

| 단계 | 장소 | 설교 본문 |
|---|---|---|
| 0막 부두 | 갑판 | 개회 · 요한복음 20:30-31 |
| 1막 출항 | 선장실 | 개회 · 요한복음 20:31 |
| 2막 폭풍 | 조타실 | 1과 · 누가복음 8:22-25 |
| 3막 무덤 섬 | 화물칸 | 2과 · 누가복음 8:26-39 |
| 4막 돌아온 항구 | 선원실 | 3과 · 누가복음 8:40-56 |
| 5막 등대 | 등대 | 폐회 · 누가복음 9:1-6 |

**소요 시간은 한 팀에 약 80분**입니다.

### 가장 중요한 원칙 하나

**이 게임은 태블릿만으로는 절대 끝나지 않습니다.**

단계마다 **태블릿 밖에서 해야 하는 일**이 있습니다. 서약문을 소리 내어 읽고, 밧줄로 매듭을 묶고,
서로의 종이 사슬을 끊어 주고, 필름을 겹쳐 보고, 등대 부품을 조립합니다.
**그래서 네 명이 흩어져야 하고, 선생님이 필요합니다.**

한 학생이 태블릿만 붙들고 있으면 게임이 앞으로 나가지 않습니다. 그것이 이 게임의 설계입니다.

## 2. 행사 당일 준비 순서

### 하루 전 또는 아침에

**① 인쇄물을 뽑습니다**

인터넷 주소창에 다음을 칩니다.

```
neoix.kr/songsan/escape/print
```

화면 오른쪽 위 **[🖨 인쇄 / PDF로 저장]** 단추를 누르면 인쇄됩니다.
A4 용지로 **10장** 나옵니다.

> **주의** — 「성경 임무 카드」 아래쪽에 **선생님 확인용 정답**이 적혀 있습니다.
> 학생에게 줄 때는 **그 줄을 가위로 잘라내고** 주십시오.

**② 인쇄물을 잘라서 나눕니다**

가위 표시(✂)가 있는 점선을 따라 자르면 됩니다.

**③ 물건을 제자리에 놓습니다**

9장 [준비물 점검표](#9)를 보고 하나씩 놓아 주십시오.

**④ 태블릿을 켜 둡니다**

팀 수만큼(보통 3대) 준비하고, 각 태블릿에서 인터넷 주소창에 다음을 칩니다.

```
neoix.kr/songsan/escape/
```

> **끝에 빗금( / )을 꼭 붙이십시오.** 빠지면 그림이 안 나올 수 있습니다.

**⑤ 선생님 화면을 띄웁니다** (총괄 선생님 노트북 또는 태블릿)

```
neoix.kr/songsan/escape/admin
```

비밀번호 **3574** 를 넣으면 들어갑니다.

## 3. 태블릿(패드) 다루는 법

### 게임 시작하기

1. 화면에 **「항해 허가 요청 — 관리자」** 단추가 보입니다. 누릅니다.
2. 비밀번호 **3574** 를 넣습니다. *(선생님이 직접 넣어 주십시오. 학생에게 알려주면 안 됩니다.)*
3. 팀 이름을 고릅니다.
4. **「출항」** 을 누르면 시간이 흐르기 시작합니다.

### 화면 구성

```
┌──────────────────────────────────────────┐
│ 갑판   00:12   💡힌트  🔊  🧭지도  나가기 │  ← 위쪽 줄
├──────────────────────────────────────────┤
│                                          │
│           (배 안 그림)                    │  ← 여기를 손가락으로 누른다
│                                          │
├──────────────────────────────────────────┤
│  지금 할 일 · 부두                        │  ← 아래쪽 안내
│  [찾기] 놋쇠 열쇠 찾기                     │
├──────────────────────────────────────────┤
│  ⚪⚪⚪⚪⚪⚪⚪⚪                          │  ← 모은 도구
└──────────────────────────────────────────┘
```

| 부분 | 설명 |
|---|---|
| **왼쪽 위 글자** | 지금 있는 방 이름 |
| **가운데 숫자** | 지나간 시간 |
| **💡 힌트** | 힌트를 받거나 선생님을 부를 때 |
| **🧭 지도** | 배 전체를 보고 다른 방으로 갈 때 |
| **가운데 그림** | **아무 데나 눌러 보게 하십시오.** 물건마다 반응이 있습니다 |
| **아래 안내** | **지금 무엇을 해야 하는지** 알려줍니다. 학생이 헤매면 여기를 읽어 보라고 하십시오 |
| **맨 아래 동그라미 8개** | 모은 도구. 얻으면 밝아집니다 |

### 방 옮기기

- 화면 **양옆의 화살표( ‹  › )** 를 누르면 옆방으로 갑니다
- **🧭 지도** 를 누르면 배 전체가 보이고, 방 이름을 눌러 바로 갈 수 있습니다

## 4. 선생님 여섯 분의 자리와 할 일

| 번호 | 역할 | 자리 | 언제 | 무엇을 하나 |
|---|---|---|---|---|
| **①** | **선장** | 부두(입구) | 0막 | 서약문 낭독을 지켜보고 손등에 도장 |
| **②** | **갑판장** | 선장실 구역 | 1막 | 매듭을 검사하고 **나무 십자가**를 건넴 |
| **③** | **신호수** | 복도 끝 (불을 어둡게) | 2막 | 손전등으로 빛 신호를 보냄 |
| **④** | **거라사** | 화물칸 구역 | 3막 | 사슬 끊기를 지켜보고 **기름·부싯돌**을 건넴 |
| **⑤** | **총괄** | 자유롭게 이동 | 내내 | 선생님 화면을 보며 막힌 팀을 도움 |
| **⑥** | **등대지기** | 등대(무대) | 5막 | 짐 검사, 등대 불 켜기 |
| **목사님** | **4막 선원실 옆 별도 자리** | **「선장을 찾는 세 물음」 + 선장의 인장** (건너뛸 수 없는 관문) |

> **다섯 분만 계셔도 됩니다.** ⑤ 총괄이 ①선장을 겸하면 됩니다(0막은 처음에만 필요).

### 선생님이 지켜야 할 것 세 가지

1. **정답을 먼저 말하지 마십시오.** 아래 [6장](#6)의 방식으로만 도와주십시오.
2. **비밀번호 3574는 절대 알려주지 마십시오.** 학생이 알면 게임 전체가 열립니다.
3. **성경 도우미는 쪽수만** 알려주십시오. 내용은 학생이 찾게 하십시오.

<a name="5"></a>
## 5. 막별 진행 — 무엇을 보고 무엇을 해 주나

각 막마다 **① 학생이 하는 일 → ② 선생님이 하는 일 → ③ 넘어가는 조건** 순서로 적었습니다.

---

### 0막 · 부두 (갑판) — 담당: ① 선장

**이야기** — 배에 오르려면 승선 명부에 이름을 올려야 한다.

**① 학생이 하는 일**
1. 태블릿에서 갑판의 물건들을 눌러 봅니다 → **밧줄 더미**에서 **놋쇠 열쇠**를 찾습니다
2. **나무 궤짝**(승선 명부함)을 누르면 「팀 미션」이 뜹니다
3. 부두 이젤 앞에 넷이 서서, **서약문 네 줄을 한 사람씩** 이어 읽습니다
4. **마지막 줄은 넷이 함께** 큰 소리로 외칩니다
5. 각자 명부에 **이름과 고백 한 줄**을 씁니다

**② 선생님(선장)이 하는 일**
- 네 명이 **골고루** 한 줄씩 맡았는지 봅니다 (한 명이 다 읽으면 다시 시키십시오)
- 마지막 줄을 **정말 함께** 외쳤는지 봅니다
- 다 되면 **손등에 도장**을 찍어 줍니다

**③ 넘어가는 조건**
- 학생이 태블릿에서 **「넷이 함께 서약하고, 각자 서명했다」** 단추를 누릅니다
- **열쇠도 찾아야** 다음 막으로 갑니다

---

### 1막 · 출항 (선장실) — 담당: ② 갑판장

**이야기** — 선장이 없다. 그의 방에서 출항 명령을 찾아야 한다.

**① 학생이 하는 일**
1. 선장실 **책상**을 누릅니다 → 열쇠로 열려 **자외선 등불**이 나옵니다
2. **책상을 한 번 더** 누릅니다 → 「보이지 않는 잉크」 문제가 나옵니다
   - 텅 빈 허가증을 자외선 등불로 비춰 숨은 글씨를 읽는 문제입니다
   - **정답: 생명**
3. **낡은 해도**를 누릅니다 → 「출항 삭구」 미션이 나옵니다
4. 네 명이 밧줄의 네 지점에 흩어져 **매듭을 하나씩** 묶습니다
5. 다 묶이면 함께 **돛천을 올립니다**
6. 태블릿으로 돌아와 **닻**과 **돛**을 눌러 배를 출발시킵니다

**② 선생님(갑판장)이 하는 일**
- 매듭 도해 카드와 **실제 매듭을 대조**해 봅니다
- 이름이 정확하지 않아도 **단단히 조여졌으면** 통과입니다
- 통과하면 **나무 십자가를 손에 쥐여 줍니다** ← 3막에서 꼭 필요합니다

**③ 넘어가는 조건**
- 「보이지 않는 잉크」 정답 + 「갑판장의 매듭 검사를 통과했다」 단추 + 닻·돛 조작

---

### 2막 · 폭풍 (조타실) — 담당: ③ 신호수

**이야기** — 광풍이 배를 삼킨다. 침로를 되찾아야 한다.

**① 학생이 하는 일**
1. 조타실에서 문제 네 개를 풉니다
   - **해도** → 정답 **B7**
   - **등불**(무전) → 정답 **82425**
   - **승강구**(젖은 항해일지) → 첫 칸 정답 **베개**
   - **액자 그림**(도둑 쪽지) → 정답 **나3**
2. **항해 궤**를 누르면 「빛 신호」 미션이 나옵니다
3. **한 명만** 복도 끝 신호수 선생님께 갑니다
4. 빛 신호를 받아 적어 돌아옵니다
5. 태블릿 **두드림판**에 그 리듬대로 누릅니다 (길게/짧게)
6. **조타륜**을 눌러 침로를 잡습니다

**② 선생님(신호수)이 하는 일**
- 불을 어둡게 한 복도 끝에 서 있습니다
- 손전등으로 이 리듬을 **정확히 세 번** 보냅니다

> ### 보낼 신호: **길게 — 짧게 · 짧게 · 길게**
> - **길게** = 손전등을 약 1초 켰다 끔
> - **짧게** = 툭 하고 짧게 켰다 끔
> - 신호 사이에는 잠깐 꺼 둡니다

- **팀에서 한 명만** 받으러 옵니다. 여럿이 오면 돌려보내십시오.
- **말로 알려주면 안 됩니다.** 빛으로만 보내십시오.
- 네 번째 요청부터는 총괄 선생님께 알려 주십시오.

**③ 넘어가는 조건**
- 문제 네 개 + 두드림판 리듬 성공 + 조타륜 조작

---

### 3막 · 무덤 섬 (화물칸) — 담당: ④ 거라사

**이야기** — 무덤에 매여 살던 사람이 어떻게 풀려나는가.

> **먼저 확인** — 학생들이 **나무 십자가**를 가지고 있어야 상륙할 수 있습니다.
> 없으면 1막 갑판장에게 다시 보내십시오.

**① 학생이 하는 일**
1. 화물칸 문제 세 개를 풉니다
   - **자루**(이천의 비밀) → 정답 **2000**
   - **그림자**(네 개의 다이얼) → 무덤 → 사슬 → 돼지 → 집 순서
   - **술통**(거꾸로 쓰인 편지) → 정답 **새사람전하라**
2. **어망**을 누르면 「사슬 끊기」 미션이 나옵니다
3. 네 명이 **종이 사슬로 서로 얽힙니다**
4. **자기 사슬은 자기가 못 끊습니다.** 한 사람씩 「나를 묶는 것」을 한마디 말하면, **옆 사람이 그 사슬을 끊어 줍니다**
5. 넷이 다 풀리면 **십자가를 세우고** 함께 선포합니다
6. **기둥**을 눌러 하중을 정렬합니다

**② 선생님(거라사)이 하는 일**
- 사슬은 **손으로만** 끊게 하십시오. 잡아당기면 넘어집니다.
- 네 명이 **전부** 풀렸는지 확인합니다
- 십자가를 세웠는지 확인합니다
- 다 되면 **기름통과 부싯돌**을 건네줍니다 ← 5막에서 꼭 필요합니다

**③ 넘어가는 조건**
- 문제 세 개 + 「서로의 사슬을 다 끊었다」 단추 + 하중 정렬

---

### 4막 · 돌아온 항구 (선원실) — 선생님 판정 없음

**이야기** — 열두 해 앓은 여인과 열두 살 소녀.

**① 학생이 하는 일**
1. 선원실 문제 세 개를 풉니다
   - **해먹**(군중 속의 손) → 정답 **11**  *(벽에 붙인 큰 포스터를 보고 풉니다)*
   - **찬장**(레핀의 방) → 정답 **129**  *(벽에 붙인 그림과 손거울을 씁니다)*
   - **장화**(소녀를 깨운 말) → 정답 **달리다굼**
2. **나무 궤짝**을 누르면 「그 한 사람」 미션이 나옵니다
3. 네 명이 각자 **반투명 필름 한 장**을 듭니다
4. **네 모서리를 동시에 맞잡아** 빛에 비춥니다 → 한 얼굴만 드러납니다
5. 태블릿에 **믿음** 이라고 씁니다

**② 선생님이 하는 일**
